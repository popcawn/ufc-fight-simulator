Fair odds & value calculator

"Fair odds" is the model's no-vig price for each outcome. Type a sportsbook's American odds (e.g. -150 or +220) to see your expected value — green = positive EV (the book is paying more than the model thinks it's worth). Market % is the book's no-vig probability (vig removed on the two-way win/distance markets) — compare it to Model % to see where you actually disagree with the line. When the verdict says pass, green flags are downgraded to ⚠ suspect. Props are estimated from the simulation's method/round mix. Read the honesty note before betting.

Honesty note: no fight model on earth hits 90% — Vegas favorites win ~65% of UFC fights and published ML models top out around 65–72%. This model scored 65.8% on 585 held-out fights (every UFC fight Jan 2025 – Jun 2026, predicted using only pre-fight data — no leakage, no hardcoding; see ufc-eval.mjs). The small 28-fight table above uses current stats and is for illustration. Treat single-fight picks as probabilities, not certainties.
Refreshing the data: run node ufc-build-roster.mjs — it downloads the latest UFCStats dataset (Greco1899/scrape_ufc_stats on GitHub, auto-updated after every event), recomputes all fighter stats, and re-injects the roster into this file. Records shown are UFC fights only.
